# UI Package

This package contains presentation layer components and screens:
- `theme/`: PixelQuest color palette, typography (Press Start 2P font), shapes, and Compose Theme wrapper.
- `components/`: Custom retro 8-bit UI elements (`PixelButton`, `PixelCard`, `PixelDialog`, `PixelProgressBar`, `PixelBottomNavBar`).
- `screens/`: Feature screens (`SplashScreen`, `HomeScreen`, `TasksScreen`, `StatsScreen`, `ProfileScreen`).
- `navigation/`: NavHost navigation graph setup.
