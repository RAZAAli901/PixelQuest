# Tracked follow-up work

There are no open code TODOs at this baseline. `TodoAuditTest` enforces that `src/main/java`
contains no unresolved `TODO` comments.

When work cannot be completed in the same change, do not leave a code comment as a reminder. Add a
short entry here with its owner/context, the user or engineering impact, and the verification needed
to close it; then remove the entry in the commit that resolves it.
